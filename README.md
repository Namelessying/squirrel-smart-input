# Squirrel Smart Input

一套面向 macOS 鼠须管的隐私优先智能配置，体验目标是接近微软拼音与搜狗输入法的候选效率，同时保留 Rime 的可控性。

> 本项目不是“绝对零泄露”的承诺。默认离线；只有用户主动开启“云候选”后，当前尚未上屏的拼音串才会发送给搜狗服务。项目不会读取或上传个人词典、学习库与输入历史。详见 [隐私说明](docs/PRIVACY.md)。

## 主要特性

- 搜狗云候选可选启用，默认关闭；联网结果最多占据前 5 个候选。
- 本地快速学习：多字词选一次进入首屏，选两次超过云候选。
- 汉字单字选一次即可成为强偏好；假名、标点、Emoji 和单个英文字母不参与学习。
- 同时学习完整拼音和首字母简拼，例如 `niubi` 与 `nb`。
- 超级简拼与有限错拼纠正，错拼提示只显示简短的正确拼音。
- 横排 7 候选，候选窗口为雾凇默认尺寸的 90%。
- 左 Shift 在鼠须管内部切换中英文，Caps Lock 保留大写行为。
- 中文模式下输入 `no`，固定首选 `の`；不加入其他日语假名。
- 本地上下文预测与学习数据只保存在用户自己的电脑上。

## 隐私设计

公开仓库采用文件白名单制作，不包含：

- 个人词典、手机词库和自定义短语；
- `*.userdb`、同步目录、安装标识；
- 本地快速学习记录与搜狗缓存；
- 构建产物、日志、备份和本机路径；
- 未经说明的原生二进制文件。

公开版中的错拼词表只由雾凇的公开基础词库生成，不读取手机词库或用户词典。仓库自带隐私检查脚本，并在每次 GitHub 提交时自动检查。

## 安装

### 1. 安装基础方案

先安装 [鼠须管](https://github.com/rime/squirrel) 和 [雾凇拼音](https://github.com/iDvel/rime-ice)。

当前公开配置默认启用本地上下文预测，因此需要按雾凇官方文档安装语法模型：

```sh
bash rime-install iDvel/rime-ice:others/recipes/grammar:schema=rime_ice
```

### 2. 备份个人配置

在覆盖任何 `.custom.yaml` 前，请先备份自己的 `~/Library/Rime`。本项目不会提供自动删除或覆盖用户词典的脚本。

### 3. 复制公开配置

将仓库根目录的三个 `.custom.yaml`、错拼文件及 `lua/` 目录中的 Lua 文件复制到 `~/Library/Rime` 对应位置，然后从鼠须管菜单选择“重新部署”。

### 4. 可选：启用云候选

云候选依赖 `simplehttp` Lua 模块。本仓库不直接分发来历不透明的二进制文件；请从 [hchunhui/librime-cloud](https://github.com/hchunhui/librime-cloud) 的源码或 Releases 获取与你的 macOS 架构和 Lua 版本匹配的模块，自行核对来源，并把模块放到 `~/Library/Rime/lua/simplehttp.so`。

没有安装该模块时，配置会安静地保持离线，不影响本地输入。

安装后，在鼠须管方案菜单中将“离线”切换为“云候选”。具体联网数据见 [隐私说明](docs/PRIVACY.md)。

## 本地学习规则

- 多字词第一次选择：进入首屏，但保留原排序前两个候选。
- 多字词第二次选择：超过云候选并置顶。
- 汉字单字第一次选择：直接作为强偏好置顶。
- `Shift+Delete` 或 `Control+Delete`：删除所选词在所有已学习编码下的记录。
- 学习文件：`~/Library/Rime/quick_memory.tsv`，不会被本项目上传。

## 数据重置

- 删除快速学习：退出鼠须管后删除 `quick_memory.tsv`。
- 删除云候选缓存：退出鼠须管后删除 `sogou_cloud_cache.tsv`。
- 关闭联网：在方案菜单切回“离线”。公开版每次重新部署默认离线。

## 发布前隐私检查

```sh
./scripts/privacy_audit.sh
```

检查会拒绝个人词典、学习数据库、缓存、二进制文件、本机绝对路径等内容进入发布包。
